# LATENCY POLICY

## LATENCY THRESHOLDS:
- CRITICAL: > 150ms latency
- HIGH: 100-150ms latency  
- MEDIUM: 70-100ms latency
- LOW: < 70ms latency

## WAN REROUTING RULES:
- CRITICAL: Use 3 WANs, reroute devices equally
- HIGH: Use 2 WANs, reroute devices equally
- MEDIUM: Use 2 WANs, reroute devices equally
- LOW: No action needed

## EXECUTION:
1. Get latency from appliance settings
2. Get device list from uplink statuses and note the counts all wan has how many device conenected
3. Check latency against thresholds
4. Reroute devices equally across required WANs
5. Report final rerouting results
